# Android Compose Starter

Базовый Android-проект на Kotlin + Jetpack Compose.

## Что уже настроено
- Kotlin + Android Gradle Plugin
- Jetpack Compose + Material 3
- Структура `app` модуля

## Требования
- Android Studio (рекомендуется актуальная стабильная версия)
- JDK 17
- Android SDK Platform 34
- Android SDK Build-Tools (последняя версия)

## Запуск
1. Откройте проект в Android Studio.
2. Дождитесь Gradle Sync.
3. Выберите эмулятор или подключенное устройство.
4. Нажмите Run.

## Важно для Windows
Используйте ASCII-путь к проекту (например `C:\\1-android-app`), чтобы избежать ошибок Android/Gradle при проверке путей SDK.
