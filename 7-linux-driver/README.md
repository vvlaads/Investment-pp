Этот проект представляет собой учебный драйвер устройства для ядра Linux, который имитирует генерацию биржевых котировок (тикер, Bid, Ask, объем) и предоставляет их пользователю через символьное устройство.

## Архитектура
Драйвер построен на принципах модульности:
- **Core Engine:** Управляет таймером и синхронизацией данных (Producer-Consumer).
- **Generators:** Модуль генерации цен (на данный момент реализован `random_walk`).
- **Formatters:** Модуль сериализации (на данный момент реализован `csv`).
- **Transport:** Символьное устройство `/dev/quotes` для передачи данных в User Space.

## Системные требования
- Linux (Ubuntu/Debian рекомендуется)
- Заголовки ядра: `sudo apt install build-essential linux-headers-$(uname -r)`
